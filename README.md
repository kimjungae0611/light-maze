# 「빛의 미로: 사라진 에너지 코어」 (10단계 완성판)

중학교 과학 교육과정의 **‘빛의 직진’**과 **‘빛의 반사 법칙’**을 학생들이 직접 조작하고 예측하며 체득할 수 있도록 개발된 시뮬레이션 웹게임입니다.

---

## 1. 전체 이야기 및 4대 구역 구성

정전으로 멈춰버린 미래 도시의 **10개 에너지 코어**를 광학의 원리를 활용해 복구하는 여정입니다.

| 구역 | 단계 | 핵심 주제 | 주요 학습 및 미션 목표 |
| :--- | :--- | :--- | :--- |
| **제1구역: 광학 연구소** | 1단계: 빛의 첫걸음 | 빛의 직진 | 광원 방향을 조절하여 첫 번째 코어 점등 |
| | 2단계: 거울 한 장의 비밀 | 반사의 법칙 (법선, 45°) | 거울 1개로 빛을 90° 꺾어 두 번째 코어 점등 |
| | 3단계: 벽 너머의 신호 | 2회 반사 & 장애물 우회 | 거울 2개로 중앙 벽을 우회하여 1구역 완료 |
| **제2구역: 지하 에너지 통로** | 4단계: 꺾인 통로 | 꺾인 통로 자율 설계 | 새로운 벽 배치와 광원 방향에서 2회 반사 설계 |
| | 5단계: 에너지 체크포인트 | 투과형 센서 경유 | 체크포인트를 관통한 후 수신기에 도달 |
| | 6단계: 흡수 구역을 피해라 | 흡수 패널 우회 | 빛을 소멸시키는 붉은 흡수 패널을 피해 우회 |

## 2. 핵심 과학 원칙

1. **빛의 직진**: 균일한 매질(공기) 안에서 빛은 휘어지지 않고 직선으로 곧게 나아갑니다.
2. **법선(Normal)**: 빛이 거울에 닿는 충돌 지점에서 거울 면과 직각($90^\circ$)을 이루는 가상의 기준선입니다.
3. **반사의 법칙**: 
   - **입사각과 반사각의 크기는 항상 같습니다** ($\theta_i = \theta_r$).
   - 두 각도는 거울 면이 아닌 **반드시 법선을 기준으로 측정**합니다.
   - 반사 벡터 계산 공식: $\vec{r} = \vec{d} - 2(\vec{d} \cdot \vec{n})\vec{n}$
4. **흡수와 차단**: 벽과 흡수 패널은 빛을 통과시키지 못하며, 흡수 패널에 닿은 빛은 그 자리에서 소멸합니다.
5. **센서의 투과성**: 체크포인트 센서는 빛의 진로를 바꾸거나 막지 않고 통과시킵니다 (센서 통과 및 코어 점등 유지는 교육용 게임 장치입니다).

## 3. 실행 방법

본 게임은 순수 웹 표준(HTML5, CSS3, ES6 JavaScript, Canvas 2D, Web Audio API)만으로 개발되어 별도의 서버나 라이브러리 설치 없이 즉시 실행됩니다.

### 간편 실행 (더블 클릭)
1. 탐색기에서 `light-maze` 폴더를 엽니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari), 웨일(Whale) 등 브라우저로 엽니다.

### 로컬 웹 서버 실행 (선택 사항)
```bash
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 4. 조작 가이드

- **거울 배치**: 하단 도구함의 [회전 거울]이 선택된 상태에서 캔버스의 점선 [거울 슬롯]을 클릭합니다.
- **거울 회전 및 회수**: 설치된 거울을 클릭하면 나타나는 플로팅 팝업에서 `↺ 45°`, `↻ 45°`를 눌러 각도를 변경하거나 `✖ 회수`를 눌러 도구함으로 되돌립니다.
- **빛 발사**: `⚡ 빛 발사` 버튼을 누르면 빛이 실시간 궤적을 그리며 발사됩니다. (발사 중 배치 수정 방지)
- **법선·각도 관찰기**: `🔬 관찰기` 버튼을 누르면 충돌점에 법선 점선과 입사각, 반사각 크기가 표시됩니다.
- **단계별 힌트**: `💡 힌트` 버튼으로 단계별 3단계 힌트(관찰 대상 ➜ 경로 안내 ➜ 구체적 설치 위치)를 확인합니다.
- **초기화**: `🔄 초기화`를 누르면 현재 단계의 거울 배치 및 다중 수신기 점등 상태가 초기화됩니다.

├── style.css           # 연구소 SF 만화 테마 스타일, 4개 구역 및 배지 반응형 레이아웃
