# 「빛의 미로: 사라진 에너지 코어」

중학교 과학 교육과정의 **‘빛의 직진’**과 **‘빛의 반사 법칙’**을 학생들이 직접 조작하고 예측하며 체득할 수 있도록 개발된 시뮬레이션 웹게임입니다.

---

## 1. 게임 개요 및 학습 목표

도시의 전력을 공급하던 3개의 에너지 코어가 정지했습니다. 플레이어는 광학 연구소의 탐험가가 되어 빛의 경로를 예측하고 거울을 회전·배치하여 3개의 에너지 코어를 모두 복구해야 합니다.

### 핵심 과학 원리
1. **빛의 직진**: 빛은 균일한 매질(공기) 안에서 꺾이지 않고 직선으로 나아갑니다.
2. **법선(Normal)**: 빛이 거울에 닿는 충돌 지점에서 거울 면과 직각($90^\circ$)을 이루는 가상의 기준선입니다.
3. **반사의 법칙**: 
   - **입사각과 반사각의 크기는 항상 같습니다** ($\theta_i = \theta_r$).
   - 두 각도는 거울 면이 아닌 **반드시 법선을 기준으로 측정**합니다.
   - 반사 벡터 계산 공식: $\vec{r} = \vec{d} - 2(\vec{d} \cdot \vec{n})\vec{n}$

## 2. 스테이지 구성 (1~3단계)

- **[1단계: 빛의 첫걸음]**
  - **학습 목표**: 빛의 직진 원리 이해
  - **조작**: 거울 없이 광원의 발사 방향(상, 하, 좌, 우) 선택
  - **결과**: 오른쪽 선택 시 수신기에 도달하여 에너지 코어 1개 점등

- **[2단계: 거울 한 장의 비밀]**
  - **학습 목표**: 거울에 의한 빛의 굴절/반사와 반사의 법칙 관찰
  - **조작**: 거울 1개를 (1, 2) 슬롯에 배치하고 $135^\circ$로 회전하여 위로 오던 빛을 오른쪽으로 $90^\circ$ 반사
  - **결과**: 법선과 입사각($45^\circ$)·반사각($45^\circ$) 관찰, 에너지 코어 2개 점등

- **[3단계: 벽 너머의 신호]**
  - **학습 목표**: 2회 연속 반사를 통한 장애물 우회
  - **조작**: 거울 2개를 각각 (1, 2)에 $135^\circ$, (6, 2)에 $45^\circ$로 배치하여 중앙 차단벽을 피해 (6, 5) 수신기로 유도
  - **결과**: 거울 1개로는 도달할 수 없음을 확인하고 2개 거울의 연계 성공, 에너지 코어 3개 모두 복구 및 도시 복구 완료 연출!

## 3. 실행 방법

본 프로젝트는 순수 웹 표준(HTML5, CSS3, ES6 JavaScript, Canvas 2D, Web Audio API)만으로 개발되어 별도의 Node.js 서버, 데이터베이스, 외부 라이브러리 설치가 전혀 필요하지 않습니다.

### 간편 실행 (더블 클릭)
1. 탐색기에서 `e:\구글바이브코딩\light-maze` 폴더를 엽니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari), 웨일(Whale) 등 선호하는 브라우저로 엽니다.

### 로컬 웹 서버로 실행 (선택 사항)
VS Code의 `Live Server` 확장을 사용하거나 파이썬 간이 서버를 열어 실행할 수도 있습니다.
```bash
# 파이썬 내장 웹 서버 실행 예시
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 4. 조작 가이드

- **거울 배치**: 하단 도구함의 [회전 거울]이 선택된 상태에서 캔버스의 점선으로 표시된 [거울 슬롯]을 클릭합니다.
- **거울 회전 및 회수**: 이미 설치된 거울을 클릭하면 나타나는 플로팅 팝업에서 `↺ 45°`, `↻ 45°`를 눌러 각도를 변경하거나 `✖ 회수`를 눌러 도구함으로 되돌립니다.
- **빛 발사**: `⚡ 빛 발사` 버튼을 누르면 빛이 실시간 궤적을 그리며 발사됩니다.
- **법선·각도 관찰기**: `🔬 관찰기` 버튼을 누르면 충돌점에 법선 점선과 입사각, 반사각 크기 및 호가 표시됩니다.
- **힌트 및 초기화**: 막혔을 때는 `💡 힌트` 버튼으로 단계별 단서를 확인하고, 처음부터 다시 해보려면 `🔄 초기화`를 누릅니다.

```
light-maze/

├── index.html          # 메인 시맨틱 UI 마크업 및 화면 컨테이너
├── style.css           # 연구소 SF 만화 테마 스타일 및 반응형 레이아웃
├── README.md           # 프로젝트 문서 및 사용 설명서
│
└── js/
    ├── optics.js       # 2D 벡터 광선 추적, 교차 검사, 반사의 법칙 물리 엔진
    ├── stages.js       # 1~3단계 맵 데이터(광원, 수신기, 벽, 슬롯, 과학 설명)
    ├── storage.js      # localStorage 진행 상황 및 음소거 설정 관리자
    ├── audio.js        # Web Audio API 기반 순수 신디사이저 사운드 효과
    └── game.js         # 캔버스 렌더러, 애니메이션 및 인터랙션 게임 컨트롤러
```
